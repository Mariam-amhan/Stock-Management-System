# Stock Management System

A desktop stock management application developed using C# and Windows Forms.

## Features

- User Login System
- Category Management
  - Add Category
  - Update Category
  - Delete Category
- Product Management
  - Add Product
  - Update Product
  - Delete Product
- Stock Tracking
- Critical Stock Filtering
- Data Storage using TXT Files

## Technologies Used

- C#
- Windows Forms
- .NET Framework 4.7.2
- System.IO

## Project Structure

- Data
- Models
- UI
- Forms
